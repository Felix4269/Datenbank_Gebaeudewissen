# Vorwort – Glossar und Physikalische Konstanten

Glossar
Wärmeabgabesystem: System zur Abgabe der Heizwärme in einem beheizten Raum.
Beispiele: Radiator, Bodenheizung.
Wärmeerzeuger: Auch: Heizung. Heizgerät zur erzeugung von Wärme für
die Raumheizung. Beispiele: Öl-Kessel Heizung, Luft-Wasser
Wärmepumpe.
WP: Wärmepumpe
LuWa-WP: Luft / Wasser Wärmepumpe. Diese Wärmepumpe bezieht die
Heizwärme aus der Umgebungsluft
> 📖 Simulation: [[01_3c_Untervarianten|IDA ICE Tutorial – Untervarianten: Luft-Wasser WP]]

SoWa-WP: Sole / Wasser Wärmepumpe. Diese Wärmepumpe bezieht die
Heizwärme aus einer Erdsonde.
> 📖 Norm: [[_SIA_384-6_2021_MOC|SIA 384/6:2021 – Erdwärmesonden & Auslegung]]  ·  [[01_3c_Untervarianten|IDA ICE Tutorial – Untervarianten: Sole-Wasser WP]]

Physikalische Konstanten
Spez. Dichte Wasser ρ = 1kgL−1 (Näherung)
Wärmekapazität Wasser c = 4.2kJ/kgK (Näherung)
